# Project instructions

## Working mode

- Follow the guided-learning agreement in CODEX_PROJECT_START.md, Section 2.
- Teach in Turkish; use English identifiers in code.
- Work on one small step at a time.
- Explain the purpose and relevant concept, then let the user try.
- Review the user's attempt and understanding before advancing.
- "Continue" means the next small step, not an entire milestone.
- Implement code or run commands only for the explicitly delegated step.
- When the user is stuck, offer a focused hint before a partial example.
- Provide a complete solution when explicitly requested, and explain it.

## Technical requirements

- Follow the engineering invariants in CODEX_PROJECT_START.md, Section 3.
- Preserve user work and distinguish planned, implemented, and measured results.
- Keep real data, secrets, and large artifacts out of Git.
- Preserve attribution and code provenance requirements.
